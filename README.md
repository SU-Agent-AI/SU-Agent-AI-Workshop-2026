## 📋 About

SU Agent AI Workshop 2026 brings together students, researchers, practitioners, and industry professionals to explore the latest advances in autonomous and semi-autonomous AI agents. As agent-based systems increasingly shape real-world applications from scientific discovery and decision support to software engineering and robotics, this workshop provides a focused forum for sharing ideas, methods, and emerging best practices.

## 🎤 Speakers

- **Dr. Alex K. Jones** - Klaus Schroder Endowed Professor for Engineering, Syracuse University
- **Stephanie VanWagner** - Vice President, Turing Intelligence
- **Dr. Haoyu Wang** - Assistant Professor, University at Albany, SUNY
- **Dr. Jamison Heard** - Assistant Professor, Rochester Institute of Technology
- **Dr. Yuchen Wu** - Assistant Professor, Cornell University

## 📝 Topics of Interest

- LLM Agents and Learning of LLM agents
- Designing autonomous agents that can reason, plan, and act using modern frameworks and multi-agent systems
- Enabling agents to interact with APIs, databases, and external tools to perform real-world tasks autonomously
- Building systems where multiple AI agents coordinate, communicate, and solve complex problems together
- Open source software of LLM tool use and agents

## 🚀 Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/su-agent-ai-workshop-2026.git
   ```

2. Open `index.html` in a web browser or use a local server:
   ```bash
   python3 -m http.server 8000
   ```

3. Visit `http://localhost:8000` in your browser
